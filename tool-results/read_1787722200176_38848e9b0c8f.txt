     1→# Flux — Full-Stack Project Worklog
     2→
     3→## Project Overview
     4→Flux is a financial-stability platform for freelancers and gig workers. Two source assets were provided:
     5→- **flux.zip** — a polished static HTML/CSS/JS frontend (Dashboard, Spending, Income Forecast, Break Planner, Safety Vault, Profile) with 3 themes (dark/light/paper) and i18n (en/hi).
     6→- **Flux_AI.zip** — a Python Colab ML pipeline (NeuralProphet + XGBoost residual boosting) that forecasts 30 days of gig income, evaluates MAPE, and runs an automated "Vault CFO" (surplus→deposit 40%, deficit→withdraw).
     7→
     8→## Goal
     9→Rebuild Flux as a real Next.js 16 full-stack app:
    10→- Port the design system faithfully (dark/light/paper themes, Fraunces/Inter/JetBrains-Mono fonts).
    11→- Implement a TypeScript port of the hybrid forecasting engine (trend + weekly seasonality + residual boosting + 80% CI + MAPE + Vault logic).
    12→- Persist state in SQLite via Prisma (transactions, vault txs, forecast runs, chat messages, profile).
    13→- Add an LLM-powered AI CFO chat assistant (z-ai-web-dev-sdk, backend only).
    14→- Real-time vault/forecast updates over a Socket.IO mini-service (port 3003).
    15→- CSV upload to run the real forecast model on user data.
    16→- Single `/` route (view switching via client state) per project rules.
    17→- Sticky footer, responsive, accessible.
    18→
    19→## Architecture
    20→- Frontend: Next.js 16 App Router, Tailwind 4, shadcn/ui, Zustand, TanStack Query, Framer Motion.
    21→- Backend: Next.js API routes (route handlers) + Prisma (SQLite).
    22→- ML: `src/lib/forecast.ts` (pure TS port of the Python pipeline).
    23→- Realtime: `mini-services/flux-realtime/` Socket.IO on port 3003.
    24→- AI: `src/lib/llm.ts` wrapping z-ai-web-dev-sdk.
